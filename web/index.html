Load your own Diamond data

This site ships no Nintendo assets. Extract them from your own copy of Pokémon Diamond (USA), then reload:

pip install ndspy pillow numpy
python -m tools.extract path/to/diamond.nds

The extractor writes to extracted/, which the dev server serves locally and Git ignores.
